# MAT2007_20262027_Final_project

How to run:
1. Objectives of this project
This project compares serum testosterone levels between PCOS patients and healthy control patients using a Welch's t-test and plots the data for visualisation.
This is realised in the programming language python.

2. Download the data
The data is accessible under https://data.mendeley.com/datasets/mh94mxn3nh/1 (Yuan, Y. (2023). DataSet for PCOS. Mendeley Data, 1. https://doi.org/10.17632/mh94mxn3nh.1). 
The link provides 2 files but this project focuses on file 'Table-S1.xlxs'.
Download 'Table-S1.xlxs' and put it in the same folder as the code/script.
  2.1 Data cleaning
   All cleaning that the data has to undergo is coded for in the script. You do not       have to change the files contents at all.

4.  Install all packages
you may use 'pip install matplotlib numpy pandas seaborn scipy openpyxl' which is also detailed in the code or an alternative way you know works on your laptop.

5. Run the code
You can run the code with 'Run Python File'.
The code works when run, and shows you 3 figures. These may appear in a different window. A statistical summary is printed in the terminal.
If you would want to change the figures to be saved instead, you may do so in the appropriate lines in the code following the instructions given there.
